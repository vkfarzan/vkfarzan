# Hi, I'm Farzan

I build practical software and explore projects that make everyday workflows a little easier.

## Selected projects

**[Nexus Guard](https://github.com/vkfarzan/Nexus-Guard)**  
A Windows utility that pauses Hello Nexus while selected games are running, then restores it afterward. Available as an installer and a portable build.

**[Guessing Game](https://github.com/vkfarzan/guessing-game)**  
A Python command-line number game with three difficulty levels and sound effects.
